# AgentSkills: Mobile Engineer (React Native)

## 1. Core JavaScript & TypeScript Competencies

Keahlian fundamental dan tingkat lanjut dalam ekosistem bahasa yang mendasari React Native.

- **JavaScript ES6+:** Penguasaan konsep asynchronous (Promises, async/await), closures, hoisting, dan manipulasi array/object yang efisien.
- **TypeScript:** Penggunaan static typing, interfaces, types, generics, dan utility types untuk memastikan keamanan dan prediktabilitas kode.
- **Performance Optimization:** Pemahaman tentang event loop, penanganan memory leaks, dan optimasi performa eksekusi kode JavaScript.

---

## 2. React Native Fundamentals & UI Styling

Kemampuan membangun antarmuka pengguna (UI) yang responsif, lintas platform, dan berkinerja tinggi.

- **React Concepts:** Penguasaan komponen fungsional, Hooks (useState, useEffect, useMemo, useCallback), dan pembuatan custom Hooks.
- **Architecture:** Pemahaman tentang mekanisme Bridge tradisional, Fabric (New Architecture), serta TurboModules.
- **Layout & Styling:** Penggunaan Flexbox untuk tata letak, StyleSheet, dan pustaka styling populer seperti Tailwind CSS (NativeWind) atau Styled Components.
- **Animations:** Implementasi animasi yang mulus (60fps) menggunakan React Native Reanimated atau Animated API bawaan.

---

## 3. State Management & Data Handling

Pengelolaan alur data aplikasi dan sinkronisasi yang optimal.

- **Global State:** Penggunaan pustaka manajemen state modern seperti Redux Toolkit, Zustand, atau Context API untuk alur data yang terpusat.
- **Server State & Caching:** Implementasi React Query atau SWR untuk data fetching, mekanisme caching, dan pengelolaan state asinkron.
- **Local Storage:** Penggunaan solusi penyimpanan lokal yang cepat seperti MMKV, WatermelonDB, atau AsyncStorage.
- **API Integration:** Komunikasi efektif dengan RESTful API dan GraphQL menggunakan klien seperti Axios atau Apollo.

---

## 4. Native Modules & Device Integration

Penanganan fungsionalitas perangkat keras dan integrasi sistem operasi asli (iOS/Android).

- **Workflows:** Keahlian menggunakan React Native CLI (Bare Workflow) maupun ekosistem Expo secara menyeluruh.
- **Native Bridging:** Kemampuan mengintegrasikan atau menulis modul native dasar menggunakan iOS (Swift/Objective-C) dan Android (Kotlin/Java).
- **Device Features:** Akses dan pengelolaan fitur perangkat keras seperti kamera, geolokasi, biometrik, Bluetooth, dan sistem file.
- **Push Notifications:** Integrasi layanan push notification yang tangguh seperti Firebase Cloud Messaging (FCM) atau OneSignal.

---

## 5. Navigation & Routing

Perancangan arsitektur perpindahan layar dan pengalaman alur pengguna (UX) yang logis.

- **React Navigation:** Penguasaan implementasi Stack, Tab, dan Drawer navigation, serta konfigurasi deep linking.
- **Expo Router:** Penggunaan sistem file-based routing untuk struktur navigasi aplikasi yang modern dan setara dengan web.

---

## 6. Testing & Quality Assurance

Kemampuan memastikan stabilitas aplikasi melalui otomatisasi pengujian dan pelacakan masalah.

- **Unit Testing:** Penulisan tes terisolasi untuk fungsi dan logika bisnis menggunakan Jest.
- **Component Testing:** Pengujian render antarmuka dan simulasi interaksi pengguna menggunakan React Native Testing Library.
- **End-to-End (E2E) Testing:** Implementasi pengujian alur lengkap dari sudut pandang pengguna menggunakan Detox atau Maestro.
- **Debugging & Profiling:** Penggunaan tools seperti Flipper, React Native Debugger, atau Chrome DevTools untuk melacak bug dan bottleneck performa aplikasi.

---

## 7. CI/CD, Deployment & Observability

Manajemen siklus hidup rilis aplikasi dan pemantauan kinerja di lingkungan produksi.

- **Automation Pipelines:** Konfigurasi alur kerja CI/CD menggunakan Fastlane, GitHub Actions, atau Bitrise untuk otomatisasi build dan pengujian.
- **Store Deployment:** Pengalaman menangani proses build, code signing (keystore & sertifikat), dan rilis aplikasi ke Google Play Store serta Apple App Store.
- **Over-The-Air (OTA) Updates:** Penerapan pembaruan langsung ke pengguna (tanpa melalui toko aplikasi) menggunakan CodePush atau Expo Updates.
- **Crash Reporting & Analytics:** Integrasi alat observabilitas seperti Firebase Crashlytics, Sentry, atau Datadog untuk melacak error dan menganalisis metrik aplikasi.
